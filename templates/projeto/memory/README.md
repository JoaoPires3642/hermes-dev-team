# memory/ — aprendizados duráveis deste projeto

O que **não** se deriva do código: por que uma decisão foi tomada, o que já custou
caro, o que ficou pendente e por quê. Compartilhado por todos os bots e humanos.

- Um arquivo por sessão ou tema: `AAAA-MM-<assunto>.md`. Datas sempre absolutas.
- Quando um aprendizado vira regra permanente, **promova** para `.kiro/steering/`
  (ferramenta de trabalho) e deixe aqui só o registro histórico (diário).
- Sem segredos, tokens ou dados de cliente.
