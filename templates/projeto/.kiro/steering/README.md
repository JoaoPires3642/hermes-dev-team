# Steering do cliente

Coloque aqui um `.md` por assunto (o Kiro carrega automaticamente nas sessões):

- `arquitetura.md` — estrutura do solution, camadas, regra de dependência
  (ex.: sua skill `partner-hub-backend-architecture`)
- `seguranca.md` — baseline de segurança (ex.: `partner-hub-security-baseline`)
- `padroes.md` — convenções de código, testes, pipelines

**Sem segredos** — nada de chave, PAT, connection string.
